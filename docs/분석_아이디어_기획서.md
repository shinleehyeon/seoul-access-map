| 아이디어명 |  핫플 반감기 — 서울 상권은 얼마나 빨리 뜨고 식는가 |
| 제안자 |  (작성자명) |

| 요약 |  서울시 상권 추정매출 시계열로 ‘피크 대비 매출 점유율이 절반이 되기까지 걸린 기간(반감기)’을 산출하고, 연령대·상권유형·업종별 격차를 검증하여 유행형 상권의 휘발성과 창업 리스크를 진단함 |
| :---: | ----- |
| 필요성  및 목적 | **1. 분석 배경** “한국은 양은냄비처럼 빨리 끓고 빨리 식는다”는 통념이 상권에도 반복적으로 나타남. SNS·숏폼을 타고 특정 골목이 급부상했다가, 얼마 지나지 않아 매출이 꺾이고 점포가 바뀌는 사례(경리단길, 연남동 일부 골목 등)가 누적되고 있음. 기존 상권 분석은 대부분 “지금 얼마나 잘되는가”(정적 스냅샷)에 집중하며, “얼마나 빨리 변하는가”(동적 속도)를 다루는 지표는 부족함. 창업 예정자가 현재 매출만 보고 진입하면 이미 하락 국면인 상권에 들어갈 위험이 있음. **2. 문제점** 정적 지표의 착시: 현재 매출·유동이 높아도 이미 피크를 지난 상권일 수 있음. 유행 민감도 미검증: “20대가 많으면 빨리 식는다”, “골목상권이 더 휘발적이다” 같은 통념이 있으나 정량 근거가 약함. 업종 간 수명 차이 불투명: 디저트·카페와 생활밀착 업종의 지속성 차이를 한 지표로 비교하기 어려움. **3. 추진 목적** 반감기 지표 정의: 상권×업종 매출 시계열에서 피크 이후 상대 점유율이 50%로 떨어지는 기간을 개월 단위로 산출. 가설 검증: 20대 유동비율(H1), 상권 유형(H2), 업종 특성(H3)과 반감기의 관계를 통계적으로 검정. 의사결정 지원: 지도·대시보드로 “양은냄비형 vs 뚝배기형” 상권을 시각화해 창업·정책 논의의 공통 언어를 제공. |
| 분석 목표 |  **1. 분석 목표 반감기 추이·분포 규명**: 서울 상권×업종 단위로 피크 시점과 반감기(개월)를 산출하고, 최단·최장·평균 및 중도절단(censored) 비중을 정리. **가격이 아닌 점유율 기반 정의**: 원 매출이 아닌 동일 업종·분기 시 전역 대비 상대 점유율(relative share)로 정규화한 뒤 피크·반감기를 측정해 시장 전체 성장/수축 효과를 통제. **가설 검증**: H1) 20대 유동비율↑ → 반감기↓ / H2) 골목상권 반감기 < 발달·전통시장 / H3) 유행 업종 반감기 < 생활밀착 업종. **2. 활용 데이터 (확보·전처리 완료)** 서울열린데이터광장 상권분석서비스 — 추정매출 `VwsmTrdarSelngQq` (약 46만 row, 2021~2026 분기) / 추정유동인구 `VwsmTrdarFlpopQq` (약 3.5만 row) / 점포 `VwsmTrdarStorQq` (약 160만 row) / 상권영역 `TbgisTrdarRelm` (중심좌표). **3. 분석 방법** 패널 정리: 상권×업종 분기 시계열, 결측 보간, 관측 span≥4분기. 정규화: relative_share = 상권 매출 ÷ (동일 업종·분기 시 전역 합). 피크 탐지: 3분기 이동평균 + scipy find_peaks (prominence≥range×0.3), COVID 분기 피크 제외. 반감기: peak 이후 smoothed 값이 peak×0.5 이하가 되는 첫 분기까지 ×3개월. 상관·비교: Pearson/Spearman(H1), 유형·업종별 평균 반감기 및 짧은 반감기 비중. **4. 주요 분석 결과(1차)** 분석 상권 1,547곳 / 관측 반감기 평균 약 16.2개월 / 최단 3개월(포이사거리) / 최장 51개월(둔촌2동주민센터). H1(20대 비율–반감기): Pearson r≈0.035 → **기각**(효과크기 무시 수준). 짧은 업종 예: 핸드폰·PC주변기기 등 / 긴 업종 예: 일반의원·편의점 등. censored(관측창 내 50% 미도달) 비중이 커 해석 시 주의 필요. **5. 비고·리스크** COVID 피크 제외로 일부 구간 정보 손실. 관광특구 표본 소수. 상권영역은 중심점 기준(폴리곤 없음). 결측·이상치·프랜차이즈 급성장 사례가 패턴을 왜곡할 수 있음. |

| 기대효과 | **학문적 의의**: 상권 ‘휘발성’을 반감기라는 단일 지표로 정의해 문화·도시경제 논의에 실증 기반 제공. 통념(20대=짧은 수명) 기각 결과 포함으로 가설 검증의 완결성 확보. **산업적 가치**: 예비 창업자에게 “지금 매출”이 아닌 “피크 이후 속도” 관점의 상권 스크리닝 도구 제공. **정책적 활용**: 골목상권·유행 업종 지원 시 단기 버블과 장기 생활인프라를 구분하는 근거 자료. **사회적 파급효과**: 핫플 소비 문화와 지역 상권 지속가능성에 대한 공론화. **구현 현황**: 데이터 수집·반감기 파이프라인·지도/대시보드·AI 해설까지 `hotplace-halflife` 프로젝트에 구현 완료(발표·데모 가능). |
